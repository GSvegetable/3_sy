# 3_sy — 双轨卡片空间（Web / Capacitor 版）

Android 版 `BlackWorkspaceScreen` 的浏览器移植：纯黑底、巨幅幽灵排版，两条卡片轨道交叠成一组，
竖向拖动滚动，横向滑动在三个状态之间切换整组的位置。

在线预览：https://3-sy-workspace.vercel.app

## v0.10.0 — 对齐参考视频：两条轨道、三个状态

**两条轨道**

- 前轨在左：白色卡面，偶数序号卡片（触发输入 / 模型推理 / 记忆数据 / 逻辑控制 / 编排），压在上层，点击翻面。
- 后轨在右：青瓷卡面，奇数序号卡片，被前轨压住一部分，不翻面。
- **两条轨道都循环滚动**（之前后轨是有限滚动 + 越界回弹），搜索定位取最近的一圈。

**三个状态**（底部三个小点，横滑或点小点切换）

| 状态 | 位置 | 個斜读数 |
| --- | --- | --- |
| 01 EDGE | 整组推到屏幕左侧之外，只露右半组 | 95 |
| 02 LEFT | 贴左边缘，整组可见（启动状态） | 65 |
| 03 RIGHT | 贴右边缘，整组可见 | -65 |

- 位置按视口贴边计算（`presetShift`），不再是固定的 ±56dp；窗口尺寸变化时会重新贴边。
- 切换时位置、曲率、倾角一起走弹簧过冲，同时从目标位置荡开一道波纹。
- 底部「倾斜」滑条实时显示当前读数（视频里的 65 / 95 / -62），也可以手动拖动覆盖，下一次切换状态时恢复。
  读数换算为 CSS `rotateY`：`deg = 读数 × 0.2`（`TILT_TO_DEG`），白色轨取全量，青瓷轨取 -0.42 倍。
- 修正命中判定：轨道整体位移现在计入卡片的屏幕坐标，整组推到边缘后手势仍能选对轨道。

调参入口都在 `src/data.js` 的 `PRESETS`（`anchor` / `curve` / `tilt`）和 `TILT_TO_DEG`。

## v0.9.0 — 视觉与交互重写

这一版把此前零散的功能补丁整体重写，目标是让网页端在观感与手感上真正对齐原生。

**视觉**

- 补齐原生缺失的背景层：`AI AGENT` / `RIPPLE` / `WATER SYSTEM` 三组巨幅幽灵排版（`rgba(255,255,255,.085)`），压在卡片之下。
- 卡面按参考设备重做：近白冷调渐变（`#FDFEFE → #F4F9FC → #E3ECF5`）、顶部投影、发丝内描边；标题深藏青 `#001028`（衬线），副标题钢蓝 `#5A82AE` 斜体衬线。
- 青瓷材质（`#B8CBCC → #E6EFF0` + backdrop blur），压暗一档，与白色轨拉开层次。
- 透视改为舞台级 `perspective: 1400px`，轨道只保留 `rotateY` 与 `transform-origin`；此前 `perspective(8px)` 会把轨道压成畜形。
- 尺寸随视口缩放（手机 1:1，宽屏最多放大 1.35 倍），卡片间距、圆角、字号全部按同一比例推导。

**交互**

- 预设切换加入波纹转场：冲击环从焦点荡开，同时按卡片与波前的距离给每张卡面叠一层提亮。
- 搜索改用与原生一致的打分表（中文标题 / 全拼 / 首字母 / 英文副标，支持 2 字以内错别字），命中后 600ms EaseOutCubic 定位到 42% 焦点并高亮 1.6s。
- 长按抽出卡片改为：抽出后跟随手指，落在另一条轨道上即换轨，落在空白处则悬浮在场景中。
- 轨道命中判定改用卡片的实际渲染位置——弧线会把卡片推开，用基准坐标判断会选错轨道。

**结构**

源码拆成职责单一的模块，便于继续对齐原生：

```
src/
  data.js      卡片内容与三个状态预设（对应 BlackWorkspaceData.kt）
  search.js    搜索打分与编辑距离（对应 SearchMatch.kt）
  layout.js    轨道几何：弧线排布、焦点缩放
  scene.js     DOM 构建、每帧应用、翻面弹簧、波纹转场
  input.js     手势：轨道拖拽、横滑切状态、点击翻面、长按抽出
  effects.js   触觉反馈与设备姿态
  states.css   状态小点与底部「倾斜」滑条
  main.js      状态、编排与主循环
```

## 与原生版本的差异

这是基于 Android 源码重写的 Web 实现，不是把 Jetpack Compose 直接跑在浏览器里。

- 原生的 AGSL `RuntimeShader`（翻面形变、香槟霜面、玻璃波纹）无法由 CSS 等价复刻：翻面用 `rotateX` + 弹簧近似，
  霜面用渐变 + `backdrop-filter` 近似，波纹用冲击环 + 逐卡提亮近似。
- 原生的 Kyant Backdrop 真实折射 / 镜头色散以 CSS `backdrop-filter` 近似。
- 原生重力传感器用 `deviceorientation` 的 `gamma` 近似，桌面端无输入时轨道保持静止。
- 原生「倾斜」读数直接当角度用、透视极强（`cameraDistance = 8f * density`）；Web 端透视固定 1400px，读数按 0.2 倍换算成角度，
  轨道位置改按视口贴边计算，所以三个状态的观感是近似而非逐像素一致。

```bash
npm run dev
```

```bash
npm run build
```
