# 3_sy — 双轨卡片空间（Web / Capacitor 版）

Android 版 `BlackWorkspaceScreen` 的浏览器移植：纯黑底、巨幅幽灵排版，两条卡片轨道交叠成一组，
竖向拖动滚动，横向滑动在三个状态之间切换整组的位置与倾角。

在线预览：https://3-sy-workspace.vercel.app

## v0.10.0 — 对照原生源码与参考视频还原

**两条轨道**（以原生源码为准）

- 左轨：青瓷磨砂玻璃卡面，偶数序号卡片（触发输入 / 模型推理 / 记忆数据 / 逻辑控制 / 编排），**压在上层**，不翻面，圆角 18dp。
- 右轨：白色卡面，奇数序号卡片，被左轨压住一部分，点击翻面，圆角 12dp，卡片自带 -8° 的 rotateY。
- 两条轨道都循环滚动（参考视频里左轨也是循环的；原生源码里的左轨是有限滚动 + 越界回弹）。

**三个状态**（底部三个小点，横滑或点小点切换），数值与原生 `BlackWorkspaceData.kt` 一致

| 状态 | peak（dp） | curve | 倾斜读数 |
| --- | --- | --- | --- |
| 01 EDGE | -282 | 45 | 95 |
| 02 LEFT（启动状态） | 21.5 | 16 | 65 |
| 03 RIGHT | 735 | 14 | -65 |

- `peak` 是两条轨道同时的横向偏移，同时决定弧线半径下限：`半径 = max(140dp / curve%, |peak|)`。
- 倾斜作用在**整组**上，不是每条轨道各转各的：`rotateY = 读数 / 100 × 48°`，
  旋转原点 `x = 0.5 − 读数 / 100 × 0.35`（占屏宽），透视用 `perspective(1280dp)` 近似原生 `cameraDistance`。
- `peak` / `curve` / `tilt` 各走一条与原生相同的弹簧：阻尼比 0.82、刚度 200（`StiffnessLow`），所以过冲很轻，更接近视频。
- 窄屏（手机竖屏）上 `peak` 会被夹紧，避免整组被推出屏幕；平板 / 桌面按原生数值走。
- 宽屏按约 1000dp × 675dp 的平板画面整体放大（`createLayout` 的 `u`）；左边距固定 58dp，位置完全由 `peak` 决定。
- 底部「倾斜」滑条显示当前读数，也可手动拖动覆盖，下一次切换状态时恢复。
- 命中判定计入整组位移和倾斜透视，推到边缘后手势仍能选对轨道。

调参入口：`src/data.js` 的 `PRESETS`、`TILT_ROT`、`TILT_ORIGIN`、`CAMERA_DP`。

## v0.9.0 — 视觉与交互重写

这一版把此前零散的功能补丁整体重写，目标是让网页端在观感与手感上真正对齐原生。

- 背景幽灵排版（`AI AGENT` / `RIPPLE` / `WATER SYSTEM`）、卡面材质、舞台透视、波纹转场、搜索打分表、长按抽卡换轨。
- 轨道命中判定改用卡片实际渲染位置。
- 源码拆成职责单一的模块。

```
src/
  data.js      卡片内容与三个状态预设（对应 BlackWorkspaceData.kt）
  search.js    搜索打分与编辑距离（对应 SearchMatch.kt）
  layout.js    轨道几何：弧线排布、焦点缩放
  scene.js     DOM 构建、每帧应用、翻面弹簧、波纹转场、整组倾斜层
  input.js     手势：轨道拖拽、横滑切状态、点击翻面、长按抽出
  effects.js   触觉反馈与设备姿态
  states.css   状态小点、「倾斜」滑条，以及对齐原生的卡面材质覆盖
  main.js      状态、弹簧、编排与主循环
```

## 与原生版本的差异

这是基于 Android 源码重写的 Web 实现，不是把 Jetpack Compose 直接跑在浏览器里。

- 原生的 AGSL `RuntimeShader`（翻面形变、香槟霜面、玻璃波纹）无法由 CSS 等价复刻：翻面用 `rotateX` + 弹簧近似，
  霜面用渐变 + `backdrop-filter` 近似，波纹用冲击环 + 逐卡提亮近似。
- 原生的 Kyant Backdrop 真实折射 / 镜头色散以 CSS `backdrop-filter` 近似。
- 原生重力传感器只调高光强度，网页端没有对应的高光层，不使用。
- 原生 `cameraDistance` 的换算按「默认 8 英寸 ≈ 1280dp」估算，实际观感可能需要微调 `CAMERA_DP`。

```bash

npm run dev
```
