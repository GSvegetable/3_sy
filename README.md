# 3_sy — Android 双轨卡片空间的 Web 移植

## v0.8.0 — 补齐黑雾、搜索召唤与倾斜反馈

- 增加顶部/底部各 26% 的黑色渐变遮罩；拖拽卡片仍置于遮罩上方。
- 增加悬浮搜索入口，支持中文标题、全拼和首字母匹配；输入防抖 200ms，命中后以 600ms EaseOutCubic 定位到 42% 焦点，未命中不移动轨道。
- 增加短时青色命中高亮，以及浏览器支持时的设备倾斜近似反馈。
- 将透视直接应用于轨道旋转变换。
- 本轮仍未实现 AGSL/Kyant Backdrop 等价着色、双轨速度联动和完整的拖出后永久悬浮行为。

## v0.7.0 — 校准原生 3D 摄像机距离

- Android 轨道容器的 `graphicsLayer` 使用 `cameraDistance = 8f * density`；此前 Web 端给整个轨道使用 `perspective(1100px)`，与原生相机距离相差很大。
- 将 3D 透视放到舞台父级，并让双轨仅承担原生的 `rotationY` 与 `TransformOrigin`，避免把一个远距离透视值错误叠加在轨道自身。
- 这是按源码参数进行的 CSS 透视映射，不等于 Android RenderNode 的逐像素等价；需要在目标设备上继续对照校准。

## v0.6.0 — 修正原生卡片翻转结构

- 左侧瓷质轨道不再生成正反两面，也不再响应点击翻面；对应 `CardFace` 的 `effectiveFlip = if (isGoldTrack) 0f else flipAngle` 与 Frost 分支。
- 右侧普通卡片改为绕 X 轴翻转，背面绕 X 轴反向放置，不再错误地绕 Y 轴翻转。
- 翻转角与抬升改为两组独立逐帧弹簧状态；按原生目标值 180° / 1、抬升 26dp、额外弧形抬升 12dp、缩放增量 0.12 进行实现。
- 这仍不是原生 AGSL：原始资料没有提供 `createCardFlipShader()` 与 `createChampagneFrostShader()` 的函数体，Web 端暂时不能复刻其像素级着色结果。


这是 Android `BlackWorkspaceScreen` 的浏览器移植版本。预览页只保留原版的两条卡片轨道，不添加网页专属控制面板。

## v0.5.1 — 对齐原生双轨滚动动力学

- 把拖动目标值与实际轨道偏移分开，改为逐帧以 0.95 系数追随目标，和原生 `leftOffset/rightOffset`、`leftTargetOffset/rightTargetOffset` 的处理一致。
- 补入原生 0.55 / 0.45 位移低通滤波，以及拖动速度 0.35 / 0.65 的混合计算，避免用单次指针事件速度代替整段拖动速度。
- 左轨越界回弹改为阻尼弹簧近似，不再使用固定时长的线性收回；右轨仍保持循环滚动。
- 继续保留左右轨独立惯性和逐卡步进触觉反馈。

## v0.5.0 — 按原生卡片交互补齐翻面与材质

- 按 `CardFace` 的翻面过程补上抬升和缩放：翻面中段最高抬升约 38 dp，落到背面后保持约 26 dp 抬升，并放大到 1.12 倍。
- 补上反向翻回动画，正反两段分别模拟原生弹簧的抬升回落，不再只做单一的 180° CSS 旋转。
- 左侧瓷质卡面加入多层高光、细微纹理、青瓷色边缘和 backdrop blur 近似，保留原生 Frost Shader 无法由 CSS 完全等价实现的限制。
- 按原生按压状态增加轻微亮度反馈；卡片拖动时仍由拖动状态接管。
- 本轮仍不声称实现 AGSL 翻面形变、Kyant Backdrop 真实镜头折射或硬件传感器重力输入。

## v0.4.1 — 修复横向手势切换预设

- 修复从卡片表面开始横向滑动时，网页手势监听被卡片点击处理提前拦截的问题。
- 横向滑动现在可从卡片表面或轨道空白区域触发，保持卡片点击翻面和长按跨轨拖动交互。
- 对齐 Android 原版的切换方向：向右滑动进入下一个预设，向左滑动返回上一个预设。
- 保留原版的切换判定原则：横向位移需超过卡片宽度的 1.5 倍，且明显大于纵向位移；三个预设首尾不循环。
- 本次修改已推送 GitHub，并由 Vercel 自动部署。

## v0.4.0 — 按 Android 源码重建布局

- 使用原版 `BlackWorkspaceData.kt` 的 9 张卡片内容与三组 Peak / Curve / Tilt 预设。
- 按原版尺寸实现 150 × 132 dp 卡片、72 dp 堆叠步距、58 dp 左边距和 -24 dp 轨道间距。
- 按原版焦点比例、圆弧半径、三角函数坐标、焦点缩放、层级和越界透明度计算卡片位置。
- 左轨采用有限滚动与边界压缩回弹；右轨按原版奇数卡片序列循环排列。
- 保留独立轨道拖动、惯性、横向切换预设、点击翻面、长按跨轨移动和可用设备上的触觉反馈。
- 卡片正面、背面和左轨瓷质卡面按 `CardFace` 的结构与配色重新实现。

## 与原生版本的差异

这是基于 Android 源码逻辑重写的 Web 实现，不是把 Jetpack Compose 直接运行在浏览器中。Android 的 AGSL RuntimeShader、Kyant Backdrop 的真实折射/镜头效果、系统重力传感器和原生弹簧动画不能被 CSS 完全等价复刻；目前网页端对材质与部分动画使用 CSS 近似。需要继续通过原版设备截图逐项校准视觉差异，不能将当前版本描述为像素级一致。
