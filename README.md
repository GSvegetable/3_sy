# 3_sy — 双轨卡片空间

**当前版本：0.17.6**

双轨卡片空间的 Web / Capacitor 实现，保留三种空间状态、双轨滚动、卡片翻面与触控交互。

在线预览：https://3-sy-workspace.vercel.app

## 本次更新

- 0.17.6：降低卡片远离中心时的缩放幅度，让上下两端保持更自然的尺寸层次。
- 0.17.5：卡片调整为横向长方形，并加强文字区域的溢出保护。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## Android

```bash
npm install
npm run build
npx cap sync android
npx cap open android
```
