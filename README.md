# 3_sy — 双轨卡片空间（Web / Capacitor 版）

Android 版 `BlackWorkspaceScreen` 的浏览器移植：纯黑底、巨幅幽灵排版，两条卡片轨道在画面中央交叠，
竖向拖动滚动，横向滑动切换轨道预设。

在线预览：https://3-sy-workspace.vercel.app

## v0.9.0 — 视觉与交互重写

这一版把此前零散的功能补丁整体重写，目标是让网页端在观感与手感上真正对齐原生。

**视觉**

- 补齐原生缺失的背景层：`AI AGENT` / `RIPPLE` / `WATER SYSTEM` 三组巨幅幽灵排版（`rgba(255,255,255,.085)`），压在卡片之下。
- 卡面按参考设备重做：近白冷调渐变（`#FDFEFE → #F4F9FC → #E3ECF5`）、顶部投影、发丝内描边；标题深藏青 `#001028`（衬线），副标题钢蓝 `#5A82AE` 斜体衬线。
- 后轨改为青瓷材质（`#B8CBCC → #E6EFF0` + backdrop blur），压暗一档，与前轨拉开层次。
- 透视改为舞台级 `perspective: 1400px`，轨道只保留 `rotateY` 与 `transform-origin`；此前 `perspective(8px)` 会把轨道压成畸形。
- 尺寸随视口缩放（手机 1:1，宽屏最多放大 1.35 倍），卡片间距、圆角、字号全部按同一比例推导。

**交互**

- 预设切换加入波纹转场：冲击环从焦点荡开，同时按卡片与波前的距离给每张卡面叠一层提亮。
- 搜索改用与原生一致的打分表（中文标题 / 全拼 / 首字母 / 英文副标，支持 2 字以内错别字），命中后 600ms EaseOutCubic 定位到 42% 焦点并高亮 1.6s。
- 长按抽出卡片改为：抽出后跟随手指，落在另一条轨道上即换轨，落在空白处则悬浮在场景中。
- 轨道命中判定改用卡片的实际渲染位置——弧线会把卡片推开，用基准坐标判断会选错轨道。

**结构**

源码拆成职责单一的模块，便于继续对齐原生：

```
src/
  data.js      卡片内容与轨道预设（对应 BlackWorkspaceData.kt）
  search.js    搜索打分与编辑距离（对应 SearchMatch.kt）
  layout.js    轨道几何：弧线排布、焦点缩放、越界压缩
  scene.js     DOM 构建、每帧应用、翻面弹簧、波纹转场
  input.js     手势：轨道拖拽、横滑切预设、点击翻面、长按抽出
  effects.js   触觉反馈与设备姿态
  main.js      状态、编排与主循环
```

## 与原生版本的差异

这是基于 Android 源码重写的 Web 实现，不是把 Jetpack Compose 直接跑在浏览器里。

- 原生的 AGSL `RuntimeShader`（翻面形变、香槟霜面、玻璃波纹）无法由 CSS 等价复刻：翻面用 `rotateX` + 弹簧近似，
  霜面用渐变 + `backdrop-filter` 近似，波纹用冲击环 + 逐卡提亮近似。
- 原生的 Kyant Backdrop 真实折射 / 镜头色散以 CSS `backdrop-filter` 近似。
- 原生重力传感器用 `deviceorientation` 的 `gamma` 近似，桌面端无输入时轨道保持静止。
- 原生预设的 `peak`（弧心横向偏移，-282dp ~ 735dp）会把整条轨道推出屏幕（历史版本的「黑屏」就是它造成的）。
  这里保留弧线曲率与倾角两组参数，横向位移收敛到 ±56dp，保证任何预设下焦点卡片都在画面内。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## Android

```bash
npm install
npm run build
npx cap sync android
npx cap open android
```

推送 `v*` tag 会触发 GitHub Actions 构建 debug APK。
